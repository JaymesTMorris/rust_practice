# Rust Practice

Daily Rust programming practice. Working through the official Rust documentation and building projects of increasing complexity, starting with the basics.

## Rules

- Practice every day
- No AI-generated code
- No asking AI for help
- No copy-pasting code
- No following tutorials
- If something breaks, debug first before searching for answers
- Each project must compile and run before moving on

## Goal

Learn Rust.
